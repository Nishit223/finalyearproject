# 👟 Sneaker E-Commerce Website

An online sneaker shopping platform built using the **MERN stack** (MongoDB, Express, React, Node.js). This project simulates a real-world online sneaker store and includes **Stripe integration** for payment testing.

## 🚀 Features

- User authentication (signup/login)
- Browse sneakers with images, descriptions, and prices
- Add to cart & checkout functionality
- Stripe test payment integration
- Admin dashboard for product management (optional)
- Responsive UI with modern design

## 🛠️ Tech Stack

- **Frontend**: React.js
- **Backend**: Node.js, Express.js
- **Database**: MongoDB
- **Payment Gateway**: Stripe (Test Mode)
- **Other Tools**: JWT, Axios, Redux (if used), and more
